# 📚 150 Books Dataset

This repository contains a dataset with information about **150 books**, collected from real data.  
The dataset is designed to be useful for analysis, research, content creation, and software projects related to books and reading habits.

---

## 📌 Dataset Contents

For each book, the following information is provided:

- **Book Title**
- **Genre**
- **Keywords**  
  (Core themes and concepts that drive the story)
- **Estimated Daily Reading Time**  
  (An approximate amount of time required per day to read the book)

---

## 🎯 Use Cases

This dataset can be used for:

- **Data analysis and Data Science projects**
- **Book recommendation systems**
- Reading habit analysis and planning
- Educational and practice projects
- Content generation related to books and literature

---

## 🗂️ File Structure

- All data is stored in a single file  
- File format: CSV

---

## ⚠️ Notes

- The data is based on real information but may include estimations.
- This dataset is intended for educational, research, and non-commercial use unless stated otherwise.
